Esta Politica de Privacidad explica como Builty trata la informacion relacionada con su sitio web y con las aplicaciones que posee o desarrolla, incluyendo CleanCal y Ayla.

Esta politica es general para Builty. Si una aplicacion tiene una politica especifica o terminos propios, esos documentos pueden complementar esta politica para el uso de esa aplicacion.

Informacion que podemos recopilar

El sitio publico de Builty es una pagina estatica y no requiere registro, base de datos ni cuenta de usuario. Sin embargo, las aplicaciones de Builty pueden recopilar informacion necesaria para funcionar, como nombre, email, datos de cuenta, configuraciones, contenido cargado por el usuario, mensajes enviados a traves de integraciones, informacion de pago procesada por proveedores externos, registros tecnicos y datos de uso.

Como usamos la informacion

Podemos usar la informacion para:

  • Proveer, operar y mejorar los productos de Builty.
  • Crear y administrar cuentas de usuario.
  • Procesar suscripciones, pagos, pruebas y facturacion.
  • Enviar mensajes transaccionales, notificaciones y soporte.
  • Ejecutar automatizaciones solicitadas por el usuario dentro de cada app.
  • Prevenir abuso, fraude, fallas de seguridad o uso indebido.
  • Cumplir obligaciones legales, contables o regulatorias aplicables.

Servicios externos

Las aplicaciones de Builty pueden integrarse con servicios externos como proveedores de hosting, email, pagos, mensajeria, autenticacion, calendarios, inteligencia artificial, analitica o almacenamiento. Estos proveedores tratan informacion de acuerdo con sus propias politicas y solamente en la medida necesaria para prestar el servicio correspondiente.

Pagos

Cuando una aplicacion ofrece suscripciones o pagos, Builty puede usar proveedores externos para procesarlos. Builty no necesita almacenar datos completos de tarjetas de credito en sus propios sistemas. La informacion de pago se procesa bajo los terminos y politicas del proveedor de pago aplicable.

Mensajeria e integraciones

Algunas aplicaciones pueden conectarse con canales como WhatsApp, Telegram, Google Calendar u otros servicios. Al conectar una integracion, el usuario autoriza el uso de la informacion necesaria para ejecutar las funciones habilitadas, como enviar recordatorios, responder mensajes, crear alertas, sincronizar eventos o generar borradores.

Retencion de datos

Conservamos informacion durante el tiempo necesario para prestar los servicios, mantener registros operativos, resolver disputas, cumplir obligaciones legales o proteger nuestros derechos. Cuando la informacion ya no sea necesaria, podremos eliminarla, anonimizarla o conservarla solamente si la ley lo permite.

Seguridad

Builty usa medidas razonables para proteger la informacion. Ningun sistema conectado a internet es completamente seguro, por lo que no podemos garantizar seguridad absoluta.

Derechos del usuario

Segun la jurisdiccion aplicable, el usuario puede tener derecho a acceder, corregir, eliminar, limitar u oponerse al tratamiento de sus datos personales. Para ejercer estos derechos, debe usar los canales de contacto publicados en la aplicacion correspondiente o en el sitio de Builty cuando esten disponibles.

Menores de edad

Los productos de Builty no estan dirigidos a menores de edad. Si detectamos que se recopilo informacion de un menor sin autorizacion adecuada, podremos eliminarla.

Cambios a esta politica

Podemos actualizar esta Politica de Privacidad ocasionalmente. La version vigente sera la publicada en este sitio, con la fecha de ultima actualizacion.

Contacto

Para consultas de privacidad, utiliza el canal de soporte o contacto publicado en la aplicacion de Builty que estes usando. Cuando Builty publique un email legal central, este documento debe actualizarse para incluirlo.

Nota: este texto es una base operativa para publicar el sitio. Conviene que sea revisado por un profesional legal antes de usarlo como documento final.
